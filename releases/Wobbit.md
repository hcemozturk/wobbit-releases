# Wobbit 0.9.6
- Added new Wobbit face options, try them in Display settings. No artificial colors.
- Added customizable sound alerts for finished turns, permissions, questions and blocked sessions.
- Improved activity bubbles:
    - Session names and matching colored dots help you see who’s doing what.
    - Conversation shortcuts are available while agents are working too.
    - Improved navigation to the correct Codex and ChatGPT conversations.
    - Idle bubbles now fade away.
- New settings allow Wobbit to stay with you across all your desktops and full-screen apps.
- Improved Codex approval and context-compaction detection, including automatic approvals and permission changes during a session.
